# Logos

## Bot avatar

For a GitLab or GitHub bot user, use the relwolf avatar: [relwolf-avatar.png](/relwolf-avatar.png) (512 × 512 px,
rounded corners).

<img src="/relwolf-avatar.png" alt="relwolf avatar" width="160" />

## GitHub App avatar

GitHub crops app avatars to a square and shows any transparent area as a border. This version has a solid, square
background: [relwolf-app-avatar.png](/relwolf-app-avatar.png) (512 × 512 px).

Set the _Badge background color_ of the app to the same color as the avatar background: `#3a2e5e`.

<img src="/relwolf-app-avatar.png" alt="relwolf app avatar" width="160" />
