features:
  - title: Conventional Commits in, SemVer out
    details: feat, fix and breaking changes determine the next version. Everything else does not bump.
  - title: Release merge request
    details: The changelog and the new version in your project files arrive as a reviewable merge (pull) request on relwolf/main.
  - title: Tag and release on merge
    details: When the release request is merged, relwolf tags the commit and creates a release with the changelog entry.
  - title: GitLab and GitHub
    details: Use the Docker image as the image of a GitLab CI job or the GitHub Action. No daemon, no webhooks.
  - title: Monorepos and pre-releases
    details: Version packages independently and publish 1.3.0-beta.1 style pre-releases.
  - title: Your changelog, your format
    details: Changelogs are generated by git-cliff, so a cliff.toml controls groups, templates and links.
