# Configuration

relwolf is configured through a single optional file, `relwolf.yaml`, in the repository root.

- [relwolf.yaml](/configuration/relwolf-yaml): all options at a glance
- [Monorepos](/configuration/monorepos): several packages, component tags and linked versions
- [Updaters](/configuration/updaters): update the version in `package.json`, `pom.xml`, Gradle and any other file
- [Changelog (git-cliff)](/configuration/changelog): format of the changelog and release notes
